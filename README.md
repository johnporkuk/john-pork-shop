# John Pork Shop - Coming Soon

Bright, colorful coming soon landing page for the John Pork Shop merch store.

## Files in this repository

- `index.html` - Main landing page (all you need!)
- `image.jpg` - Your John Pork image
- `README.md` - This file

## How to deploy to Vercel

1. **Add your image file**
   - Save your John Pork image as `image.jpg` in this folder
   - Make sure it's a .jpg file (or update the filename in index.html if it's .png)

2. **Push to GitHub**
   - Create a GitHub repository
   - Upload these files to your repo
   - Commit and push

3. **Connect to Vercel**
   - Go to vercel.com and sign in
   - Click "Add New Project"
   - Select your GitHub repo
   - Click "Deploy"
   - Done! Your site goes live instantly

4. **Connect your domain** (optional)
   - Once deployed, go to Project Settings in Vercel
   - Add your domain under "Domains"
   - Follow the DNS setup instructions

## Need help?

The site is completely self-contained. Just:
- Make sure `image.jpg` is in the same folder as `index.html`
- That's it!
